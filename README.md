# 📖 About Project

**Explore Indonesia Travel** merupakan website wisata modern yang dibuat menggunakan **HTML, CSS, dan JavaScript**. Website ini menampilkan berbagai destinasi wisata Indonesia dengan tampilan yang interaktif dan responsif.

Website memiliki desain modern dengan fitur **video background pada halaman utama**, **slider destinasi otomatis**, **galeri gambar dengan navigasi**, informasi wisata, artikel perjalanan, serta halaman kontak yang user-friendly.

---

# ✨ Main Features

| Feature | Description |
|----------|-------------|
| 🎥 Hero Video Background | Tampilan halaman utama menggunakan video wisata sebagai background |
| 🖼️ Destination Slider | Slider gambar destinasi dengan auto-slide, thumbnail, dan navigasi |
| 📱 Responsive Design | Tampilan optimal untuk desktop, tablet, dan smartphone |
| 🖼️ Interactive Gallery | Galeri gambar dengan fitur auto-scroll dan navigation button |
| 🌐 Smooth Navigation | Navigasi halaman dengan efek scrolling yang halus |
| 📄 Travel Blog | Menampilkan artikel dan informasi seputar destinasi wisata |
| 📍 Contact Section | Form kontak dan integrasi lokasi menggunakan Google Maps |
| 🎨 Modern UI/UX | Desain modern dengan animasi dan transisi yang menarik |

# 📥 Download Asset

Folder **asset** yang berisi seluruh gambar, video, logo, dan media pendukung website dapat diunduh melalui Google Drive berikut:

🔗 **Download Asset Website Travel**

https://drive.google.com/file/d/1d6iabBfZWw5VblTLvrmSHslH_euOKIh4/view?usp=sharing

Setelah diunduh:

1. Extract file `.zip` (jika masih berbentuk zip).
2. Letakkan folder `asset` sejajar dengan file `index.html`.
3. Pastikan struktur folder menjadi seperti berikut:

```bash
Website-Travel/
│
├── index.html
├── style.css
├── javascript.js
│
└── asset/
    ├── gambar/
    ├── video/
    ├── logo/
    └── lainnya/
```

# 🚀 Installation & Running

## 1. Clone Repository

```bash
git clone https://github.com/username/explore-indonesia-travel.git
```

Masuk ke folder project:

```bash
cd explore-indonesia-travel
```

---

## 2. Download Asset

Download folder asset melalui link Google Drive yang tersedia pada bagian **Download Asset**, kemudian letakkan folder tersebut ke dalam project.

---

## 3. Run Website

Karena project ini merupakan website statis, cukup buka file:

```bash
index.html
```

menggunakan browser seperti:

- 🌐 Google Chrome
- 🌐 Microsoft Edge
- 🌐 Mozilla Firefox

atau menggunakan **Live Server pada Visual Studio Code** untuk pengalaman pengembangan yang lebih baik.
